# Job Hunt Tracker — App (Frontend)

This folder is the frontend app only (Next.js).

Full setup guide, backend steps, admin steps and demo-data import steps are in:
`../job-hunt-tracker-server/README.md` — start from there.

Quick run (after following that guide):
1. Copy `.env.example` to `.env` and set `NEXT_PUBLIC_API_URL=http://localhost:5000`
2. `npm install`
3. `npm run dev` — open http://localhost:3000
